AIRCH - Robot-based Object Placement with AprilTag Tracking

Python • Computer Vision • Robotics • AprilTag • Kinematics (FK/IK) • Elephant Robotics

AIRCH is a robotics project demonstrating precise placement of a plastic ring onto a landing platform using Aruco markers (AprilTags). The system combines computer vision, forward and inverse kinematics, and real-time position control for autonomous pick-and-place operations.

View Full Source Code & Documentation

Project Goal

The main objective was to precisely place a plastic ring onto a landing platform. The challenge was to detect the target platform using Aruco markers (AprilTags) and control the robot arm to place the object accurately using real-time image processing, precise kinematics calculations, and robust control logic.
