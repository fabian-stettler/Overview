Bachelorarbeit: WiFi CSI People Detection

WiFi CSI • Machine Learning • 3D-Pose-Schätzung • Python • PyTorch • OpenWrt

Bachelorarbeit am HSLU AI Robotics Research Lab: Erkennung und 3D-Lokalisierung von Personen allein aus WiFi-Channel-State-Information (CSI). Vier TP-Link-Router erfassen CSI-Signale, eine Intel RealSense-Kamera liefert synchronisierte Ground-Truth-Posen. Zwei Modelle (Yan-Referenzmodell und eigenes CTD-Modell mit Diffusions-Refiner) wurden auf 94'703 Samples trainiert und evaluiert — das CTD-Modell erreichte einen mittleren MPJPE von 111,87 mm.

Mensch-Roboter-Interaktion mit Unitree Go1

ROS2 • Python • YOLOv8 • MediaPipe • Vosk • Docker

Ein umfassendes Mensch-Roboter-Interaktionssystem für den Vierbeiner-Roboter Unitree Go1, entwickelt im HRI-Modul an der HSLU. Das System ermöglicht natürliche multimodale Interaktion durch Handgesten, Sprachbefehle und visuelle Personenverfolgung. Der Roboter kann einer ausgewählten Person folgen, auf Sprachbefehle reagieren und verschiedene Posen ausführen — auf Basis einer ROS2-Node-Architektur mit Sensorfusion.

Flugzeugortung per Multilateration

Raspberry Pi • RTL-SDR • Docker • Python • VPS • Multilateration

Eine verteilte Multilaterations-Infrastruktur (MLAT) zur Flugzeugortung in der Zentralschweiz, entwickelt für Armasuisse. Das System ortet Flugzeuge anhand von Transpondersignalen unabhängig von GPS-Daten — mit fünf geografisch verteilten Empfangsstationen in Rotkreuz, Zürich, Thun, Emmen und Payerne. Jede Station nutzt einen Raspberry Pi 4 mit RTL-SDR-Hardware und ADS-B-Antenne. Die Softwarekomponenten (readsb, mlat-client, tar1090) sind mit Docker containerisiert. Der MLAT-Server auf einem VPS trianguliert Flugzeugpositionen mit einer medianen Genauigkeit von ca. 2 km gegenüber GPS-Referenzdaten.

Microservice Filialbestellsystem

Java 21 • Microservices • RabbitMQ • Docker • MySQL • Hibernate

Ein verteiltes Filialbestellsystem auf Basis einer Microservice-Architektur. Das System verwaltet Kunden, Lagerbestände und Bestellungen über sieben unabhängige Services, die via RabbitMQ kommunizieren. Funktionen umfassen automatische Nachbestellung, Mahnungsprüfung, Business Logging und JWT-basierte Authentifizierung. Jeder Service hat eine eigene Datenbank — für hohe Autonomie und Skalierbarkeit. Entwickelt im Modul Software Design and Architecture (SWDA).

Roboterbasierte Objektplatzierung

Python • Computer Vision • AprilTag • Kinematics (FK/IK) • Elephant Robotics

Ein Robotikprojekt zur präzisen Platzierung eines Kunststoffrings auf eine Landeplattform mithilfe von AprilTag-Markern. Das System nutzt einen Elephant Robotics MyPalletizer 260 und kombiniert Computer Vision, Vorwärts-/Rückwärtskinematik (FK/IK) und Closed-Loop-Control. Die Steuerung erfolgt über ein Koordinatensystem mit Ursprung an der Roboterbasis — für mm-genaue Objektplatzierung in Echtzeit.
